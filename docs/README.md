# Documentation

The repository documentation is grouped by purpose:

- `architecture/` — product plans, security and system architecture;
- `guides/` — installation and recovery procedures;
- `plans/` — active or reusable roadmap documents;
- `releases/` — release notes and validation records;
- `legacy/iterations/` — historical iteration specifications and plans.

The repository root contains only the project entry point, operational launchers
and essential configuration. Generated audit evidence is kept in `reports/`.
