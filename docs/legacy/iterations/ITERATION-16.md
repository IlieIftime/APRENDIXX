# Iteração 16 — Fontes e bibliografia governadas

O catálogo desktop contém mais de mil referências sem fabricar livros ou
artigos. Combina fontes primárias curadas, metadados dos PDFs locais aprovados e
entradas granulares da documentação oficial da biblioteca padrão Python.

Cada entrada tem proveniência, autoria, tipo e URL/localizador. O conteúdo
integral protegido não é copiado para o catálogo. Os objetivos curriculares
continuam ligados a pelo menos três referências de apoio, e os IDs e URLs são
verificados como únicos.

Gate reproduzível:

```powershell
python scripts/audit_iteration16.py
```
